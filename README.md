# Hindi Sikho 🇮🇳

**Apni Language Se Hindi Sikho**

Phase 1 MVP: English → Hindi, mobile-first React + Vite app.

## Included
- Welcome / onboarding
- English → Hindi language selection
- Beginner / Intermediate / Advanced selection
- Daily goal
- Local profile
- 10 beginner lessons
- 50 vocabulary words
- Hindi + Roman Hindi + English
- Browser Hindi speech button
- 25-question quiz
- XP, streak, course progress and quiz best
- LocalStorage persistence
- Mobile-first responsive UI
- PWA manifest
- Future features marked Coming Soon

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Railway
Railway can deploy the repository using its Node/Railpack builder. The repository should contain this project at its root.

> Phase 1 deliberately does not fake login, cloud sync, AI teacher, speaking evaluation, payments, or real audio files. Those can be added in Phase 2 with a backend/database and external services.
